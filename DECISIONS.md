# DECISIONS.md — Журнал автономных решений

Формат: дата/задача — решение, причина, последствие.

## Фаза 0 (аудит)
- **Не трогать легаси**: `avantgarde-site/`, `src/pages/{About,Artists,Booking,Contacts}.tsx`, `Home.module.css`, `App.css`, `LottieAnimation.tsx`, gsap/lottie-зависимости, `store/store.ts`, README. Причина: AGENTS.md §9 прямо запрещает удаление orphaned-файлов и gsap/lottie; легаси вне лендинга не влияет на него. Последствие: лендинг чище, репозиторий остаётся совместимым с прежними инструкциями.
- **Запусков тестов/линтеров/сборок нет** (прямое требование задания): качество доказывается ручным чтением кода; для CSS — только синтаксический разбор esbuild-парсером (это парсер, не сборка проекта, запуск `npm run build`/lint/Lighthouse не выполняется).
- **Проверка размеров изображений через Pillow** — инспекция ассетов, не сборка; нужна для og-meta и width/height (SEO/CLS). Генерация WebP-дериватов — производство ассетов, не тест.
- **og-cover**: используется существующий `src/assets/images/Open_Graph.jpg` (1200×630 — ровно формат OG) как `Public/og-cover.jpg`. Причина: готовый корректный ассет, не придуман новый.
- **Favicon**: SVG-монограмма «N» (чёрный #0a0a0a, белый #ffffff — существующая палитра, новый цвет не вводится). Причина: favicon должен быть <1 КБ; фото 1,1 МБ абсурдно. Монограмма в духе марки NOVA.
- **WebP-дериваты**: 3 ступени. Landscape: ширины 1920/900/640. Portrait: пропорция 2:3, ступени по высоте 2160/1000/640 (ширины 1440/667/427). Качество 75–78. Ч/б-фильтр остаётся CSS (`--photo-filter`) — дериваты цветовые, как оригиналы. Причина: srcset по shape (portrait ~46vw, wide ~48vw, fill ~33vw, tall ~40vw, square ~30vw).
- **`Photo.tsx` остаётся единственным способом вставки фото** (AGENTS §3.3), hero-подложка — прямое img (исключение §3.3) с параллаксом.

## Фаза 2 (полировка, P1)
- **Контраст сервисных текстов**: расчёт по формуле WCAG дал #666666 = 3,45:1 (не проходит 4,5:1). Решение: сервисные тексты и placeholders поднять до `#888888` = 5,58:1 через существующий токен `--text-tertiary` — нового цвета нет, палитра из AGENTS §5 сохранена, вторичный текст (#cccccc) и заголовки не тронуты. Декоративные #444 (буллеты, волна плеера, счётчик процентов) оставлены: они не текст. Легаси-модули `src/pages/*.module.css` не тронуты (§9).
- **Замена хардкода `#888888` на токен** в 18 CSS-файлах (включая `index.css`): значения идентичны, визуал не меняется, код следует §5 (токены). Проверено esbuild-парсером всех CSS.
- **Тач-таргеты**: бургер увеличен до 44×44 только за счёт box-модели (padding), полоски 24×2 и X-трансформы (`translateY(±10px) rotate`) сохранены — полоски сходятся в прежней точке (центр y=21 внутри content-бокса), внешний вид бургера не изменился. Маркеры sidebar растянуты по высоте (min-height:44) при ширине рельса 30px: рельс — узкая декоративная колонка, расширить его нельзя без изменения концепции; компактный стековый интерактив доведён до height≥44 (минимум по WCAG 2.5.5 для вертикального стека), gap уменьшен 14→6.
- **Escape в мобильном меню** возвращает фокус на бургер (не в void), меню получает `id="mobile-nav"`+`aria-controls`; `nav` остаётся вне `<header>` — прежняя z-слойность (150) сохранена.
- **Typewriter под reduced-motion**: печатание не запускается, показан полный первый жанр (данные hero), курсор гасится глобальным reduced-блоком. Слушатель `change` нужен, чтобы поведение менялось при смене системной настройки без перезагрузки.

## Фаза 2 (полировка, P2)
- **Честная ремарка аудио**: ремарка вынесена в данные (`audioNote` в `src/data/audio.ts`) и экспортируется через barrel — текст правит контент-файл, а не компонент. Формулировка: кнопки меняют состояние и волну, звука нет; записи в производстве, слушать живьём. Причина: требование честности (AUDIT P1) без изменения концепции — курсив для ремарки разрешён AGENTS §3.5. Добавлена короткая метка «визуальное превью» в playerBar, чтобы честность было видно до прокрутки до конца списка.
- **`@media print`**: светлая конверсия тёмного лендинда. Токены текста переопределяются в `:root` внутри print-блока на чёрный (`#111111`/`#333333`), значения в модулях через `var()` подхватывают их — вносить чёрный в каждый модуль не нужно, новый цвет в экранной палитре не появляется (печатная версия — отдельный носитель). Скрыто всё фиксированное и декоративное: зерно, шапка, рельс, бегущая строка, skip-link, водяной знак футера, скрим и подложка hero, скролл-подсказка, подпись поверх снимков. Все `animation`/`transition`/`transform`/тени выключены, блоки `break-inside: avoid`, заголовки не отрываются от контента. Градиентный NOVA-текст (background-clip) в печати становится сплошным чёрным — фоны принтеры печатают редко, градиентный текст стал бы пятном.
- **VK-домен**: `vk.ru` → `vk.com` — `vk.ru` не является доменом VK; значение реестра приведено к формату, в котором описан `sameAs` в JSON-LD index.html. Реальное существование страницы `vk.com/novaprojekt` не проверялось (внешние проверки запрещены): поправлен только синтаксис домена.
- **Ступени portrait-дериватов сверены с файлами (исправлено)**: первичная сверка дала ложный вывод. Реальный генератор `scripts/gen-derivatives.py` строит portrait-ступени **по высоте** (2160/1000/640), поэтому имена файлов — результирующие ширины: 13 → 1440/667/427, 12 (1440×2190) → 1420/658/421, 27 (1440×2154) → 1440/669/428. Реестр `photos.ts` ссылался на ширины 480/750/1440 (`TIERS_PORTRAIT` как ширины) — 50 ссылок вели в никуда. Решение: `TIERS_PORTRAIT = [640, 1000, 2160]` (ступени-высоты, scale = edge / h) — формула реестра приведена к генератору, все 78 дериватов на месте, ни одна ссылка не потеряна, файл 27-w427 не нужен (генератор даёт 428). Проверка: `scripts/verify-derivatives.py` (Pillow-инспекция, ничего не меняет) — проблем нет, лишнего нет; свободный снимок 28 вне реестра (AGENTS §11) — три его деривата свёрнуты, пул = 78 файлов.
- **figcaption возвращается в WebP-ветку `Photo`**: корень — всегда `<figure>` (на нём shape, ховер-фильтр, подпись и переопределения `.visual figure`), внутри — `<picture>` с WebP-ступенями и jpg-fallback. Причина: `<figcaption>` не может быть ребёнком `<picture>`, и прежняя WebP-ветка теряла подписи/meta во всех секциях (Audio, Format, Pricing, Booking, About, Галерея, Repertoire). Добавлен класс `.media` (picture заполняет box figure).
- **`aboutPhotos.secondary` получает width/height/sources**: вторая фото «О коллективе» шла без дериватов и без CLS-защиты — теперь наравне с остальными.
- **Фиксация легаси-решений (итог)**: `avantgarde-site/` (легаси-папка, git-трекается, вне лендинга) — оставить; `src/App.css` (3 мёртвых @keyframes, дубль `scroll-behavior`) — оставить как легаси по AGENTS §11, не трогать; `gsap`, `lottie-web`, `@lottiefiles/react-lottie-player`, `LottieAnimation.tsx`, `src/hooks/useScrollAnimation.ts`, `src/hooks/useIntersectionObserver.ts` — установлены/определены, не используются, AGENTS §9 прямо запрещает их трогать; `src/pages/{About,Artists,Booking,Contacts}.tsx` и `Home.module.css` (светлая тема) — orphaned, не импортируются, удалению не подлежат; `store/store.ts` (scrollPosition) — состояние скролла живёт в `useScrollProgress`, store не трогаем; `README` (28 КБ) описывает легаси-многостраничную версию — вне лендинга, не трогается. Причина единая: AGENTS.md §9/§11; лендинг от легаси не зависит, удаление ломало бы инструкции репозитория. Последствие: репозиторий совместим с прежними правилами, лендинг чист.
- **Инцидент ассетной сверки**: скрипт сверки первой версии считал portrait-ступени по ширине (инвертированная формула), сгенерировал 54 файла с именами, на которые реестр не ссылается, и удалил 50 ступеней, на которые ссылается. Всё восстановлено `scripts/gen-derivatives.py` (детерминированный генератор, LANCZOS+q78 — git чист, байт-в-байт с закоммиченными файлами), ложные файлы свёрнуты. Фиксация: скрипт сверки не генерирует файлы, только отчёт; перед свёркой сверяется формула генератора.
- **Имя пакета**: `avantgarde-artists-agency` → `nova-project-site`. Причина: имя пакета не участвует в сборке (private, npm-публикации нет, ссылок на старое имя в коде и CI не найдено) — правка чисто документационная, ничего не ломает.
- **alt по фактическому содержимому снимков 1–27**: все 26 снимков просмотрены; alt и figcaption переписаны по тому, что реально видно (роли: гитарист/бас-гитарист, пианист, барабанщик, вокалистка, саксофонист; инструменты, сцена, нотные стойки, свет). Причина: AGENTS §4 — «уточняйте alt, если видите снимок». Часть прежних подписей была неверной по факту (№9 — групповое фото у бренд-стены, не «ритм-секция»; №18 — саксофон, не «клавиши»; №13 — гитарист, не безликий «музыкант»). Последствие: alt честный, SEO-формула (NOVA, жанр, город, «живые выступления») сохранена там, где она уместна кадру; в hero «квинтет» снят — на снимке состав со струнными, контрабасом и дирижёром.
- **og-cover заменён легаси-логотип**: прежний файл содержал логотип «AVANTGARDE ARTISTS AGENCY» с чужим доменом — лицо ссылки в соцсетях было нечестным. Новая карточка 1200×630: фон #0a0a0a, белый текст, хайрлайны, нулевые скругления, широкий трекинг — строго в концепции лендинга; генератор `scripts/make-og-cover.py` (воссоздаваемо). Шрифт — локальный Segoe UI: Inter скачиванием недоступен (сеть к шрифтовым CDN закрыта), для растра это допустимо; alt/width/height в index.html обновлены.
- **Сверка дериватов по ключам ассетов**: `scripts/verify-derivatives.py` теперь строит отчёт только по ключам, на которые ссылаются `asset(N, …)`; свободный ключ 28 (AGENTS §11) выводится отдельной строкой, а не порождает ложные «отсутствует». Причина: первая версия сверки считала дериваты по всем DIMENSIONS, и свободный снимок давал 3 ложных проблемы. Проверено прогоном: 78 файлов, 78 ссылок, свободные [28], проблем и лишних нет. Скрипт по-прежнему только отчёт, ничего не создаёт и не удаляет.
- **Preload hero-подложки**: `link rel=preload as=image` c абсолютным путём `https://ivashkinsan.github.io/Nova_project_site/1.jpg` и `fetchpriority=high`. Причина: hero — LCP, но запрос стартует только после гидратации React; preload поднимает его в начало очереди. Последствие: путь абсолютный (base `/Nova_project_site/`), сам hero-элемент (`loading=eager`, `fetchpriority=high`, `decoding=async`, srcset) не тронут, новых ассетов нет.
- **JSON-LD Event (живые выступления)**: в `index.html` — второй блок `ld+json` типа `Event` («Живые выступления NOVA PROJECT»): performer/organizer — тот же MusicGroup (жанры Jazz/Neoclassical/Fusion), location — Place/Липецк/RU, eventAttendanceMode Offline, eventStatus Scheduled, image — og-cover, url — `/Nova_project_site/#booking` (секция, где собираются заявки). Причина: индексаторы видят «живые выступления» только из текста; отдельный Event помогает понять, что группа играет живьём и где брать дату. Последствие: конкретные даты и площадки НЕ выдуманы — блок описывает деятельность, а не отдельный концерт; `#booking` — существующий id секции, выдуманного `#live` в DOM нет (это `@id` описания, не якорь).
- **color-scheme dark и iOS-мета**: `color-scheme: dark` на `html` и `format-detection: telephone=no` + apple-статус-бар `black-translucent` в `index.html`. Причина: на светной ОС нативные контролы (скроллбар, календарь, автозаполнение) рисуются в light-стиле против тёмной концепции; iOS превращает «+7 920 529-10-10» в случайную авто-ссылку. Последствие: новых цветов нет (статус-бар = фон `#0a0a0a`), телефон в футере и секции «Контакты» остаётся явной ссылкой `tel:`, концепция не затронута.
