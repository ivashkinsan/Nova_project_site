# REPORT.md — Итог автономного цикла полировки лендинга NOVA PROJECT

Задача: довести лендинг джаз-квинета до производственного стандарта (SEO, доступность, производительность, чистота кода, приятная джазовая атмосфера) **не меняя существующую визуальную концепцию**. Все решения — автономные, без вопросов к пользователю; каждый шаг зафиксирован атомарным коммитом с русским сообщением.

Контекст: React 18 SPA без роутинга, Vite 5, TypeScript strict, CSS Modules, деплой на GitHub Pages (`base: "/Nova_project_site/"`, `publicDir: "Public"`).

---

## Метод проверки (внешние запуски запрещены)

Тесты, линтеры, Lighthouse, `npm run build`, `npx tsc --noEmit` и любые внешние проверочные инструменты **не запускались** — прямое требование задания. Качество доказывалось:

1. Ручным чтением кода (каждый модуль, каждая секция, AGENTS.md §1–§11 как приоритетные правила).
2. Синтаксическим разбором каждого CSS-файла парсером `npx esbuild --loader:.css=css` (это парсер, не сборка проекта) — 28 файлов, ни одной ошибки.
3. Кросс-проверкой всех `styles.*` в `.tsx` с классами их `.module.css` (скрипт в pwsh) — ни одного MISSING.
4. Pillow-инспекцией ассетов: размеры оригиналов, размеры 78 WebP-дериватов, сверка имён с реестром `src/data/photos.ts` и генератором `scripts/gen-derivatives.py` (`scripts/verify-derivatives.py` — отчётный, ничего не создаёт и не удаляет).
5. Расчётом контраста по формуле WCAG (сервисный текст `#666666` = 3,45:1 — не проходит; токен `--text-tertiary` `#888888` = 5,58:1 — проходит).

Итоговая проверка перед последним коммитом: стили — чисто, CSS-парсинг — чисто, `git status` — чисто.

## Что сделано (11 коммитов этого цикла)

### P0 — SEO-каркас (`b3919eb`)
`lang="ru"`; уникальный title `NOVA PROJECT — джаз-квинтет из Липецка: живые выступления и атмосферные сеты`; description, keywords («название группы, жанр, город, живые выступления, джаз»), canonical; Open Graph с абсолютным `og:image` + `og:image:width/height/alt` + `og:locale ru_RU`; Twitter Cards `summary_large_image`; JSON-LD `MusicGroup` (жанры, город, `inLanguage: ru`, `sameAs` VK); `robots.txt`, `sitemap.xml`; лёгкий SVG-favicon «N»; preconnect + preload шрифта Inter (один источник, `@import` из CSS убран).

### P0 — изображения и производительность (`58fef41`, `84a6c75`)
78 WebP-дериватов (3 ступени: landscape по ширинам 1920/900/640, portrait по высотам 2160/1000/640, имена = результирующие ширины; LANCZOS, q78) — **6,3 МБ вместо 28 МБ raw-JPEG**, генератор `scripts/gen-derivatives.py`. `Photo` отдаёт `<picture>` с srcset по shape (portrait 46vw, wide 48vw, fill 33vw, tall 40vw, square 30vw), все снимки с `width`/`height` (CLS), hero — `loading="eager"` + `decoding="async"` (LCP), остальные — lazy.

### P1 — доступность (`7a443b3`, `9d509a2`, `f7d7c8d`)
Формы: `label`+`htmlFor` на каждое поле, `aria-required`, `aria-describedby` с подсказками, `inputmode`, `autocomplete`, `<fieldset>`+`<legend>` для radio-карточек, звёздки требований `#ffffff`. Skip-link → `#main`, `aria-label` у `main`. Footer-якоря — ссылками, а не `span`+onclick (crawlable, клавиатурные). Escape в мобильном меню: `aria-controls="mobile-nav"`, `aria-expanded`, возврат фокуса на бургер. Тач-таргеты ≥44×44 (бургер, nav-ссылки, CTA, маркеры рельса, radio-карточки). Typewriter под `prefers-reduced-motion` показывает полный жанр, курсор гасится. Контраст сервисных текстов поднят до 5,58:1 через существующий токен — **нового цвета нет**; `#444444` остался только декоративным (буллеты, волна, счётчик).

### P1 — возврат подписей в WebP-ветке (`6c71178`)
`<figcaption>` не может быть ребёнком `<picture>`: корень `Photo` — всегда `<figure>` (shape, ховер-фильтр, `.visual figure`), внутри `<picture className={styles.media}>` + jpg-fallback; подписи и meta вернулись во все секции (About, Repertoire, Audio, Галерея, Format, Pricing, Booking). `aboutPhotos.secondary` получил дериваты и CLS-защиту. Формула portrait-ступеней реестра приведена к генератору (`TIERS_PORTRAIT = [640, 1000, 2160]`, scale = edge/h) — все 81 ссылка srcset ведёт в существующий файл, лишних файлов нет.

### P2 — атмосфера и честность (`1d7020e`, `ff6a161`)
Аудио-секция честно объявляет: кнопки — визуальное превью программы, звука нет, записи в производстве, слушать живьём в Липецке (текст в данных `audioNote`, курсив по AGENTS §3.5, метка «визуальное превью» в playerBar). Print-конверсия: светлая подача через переопределение токенов в `:root`, скрыт фиксированный декор (зерно, шапка, рельс, бегущая строка, скрим, подложка hero, водяной знак), все анимации/тени выключены, `break-inside: avoid`, градиентный NOVA — сплошной чёрный. VK-домен `vk.ru` → `vk.com` (формат реестра и `sameAs`).

### P1 — alt по просмотренным снимкам и честный og-cover (`fd963a5`)
Все 26 снимков пула просмотрены; alt и figcaption реестра переписаны по фактическому содержимому кадров: гитарист/бас-гитарист, пианист, барабанщик, вокалистка, саксофонист, струнная группа, нотные стойки, свет и экран — без выдуманных сюжетов. Прежние подписи частично были неверны (№9 — групповое фото у бренд-стены корпоративного вечера, не «ритм-секция»; №18 — саксофон, не «клавиши»). `og-cover.jpg` — легаси-логотив «AVANTGARDE ARTISTS AGENCY» с чужим доменом — заменён монохромной карточкой NOVA 1200×630 (фон `#0a0a0a`, белый, хайрлайны, нулевые скругления, широкий трекинг — только существующая палитра), генератор `scripts/make-og-cover.py`; `og:image:alt` обновлён.

### P2 — код (`d070d27`, `2c9b51c`)
Имя пакета `avantgarde-artists-agency` → `nova-project-site` (правка документационная, ссылок на старое имя нет). Единственное нарушение §3.5 — скругление скролл-полосы 4px → 0.
